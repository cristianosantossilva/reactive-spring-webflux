# reactive-spring-webflux
Spring Webflux

## Descrição projeto

Projeto voltado para consulta de filmes e suas analises.

## Definição arquitetural

Projeto definido no padrão de microserviço

### Microserviços

- movies-info-service

    Microserviço com informações sobre os filmes.

- movies-info-service 

    Microserviço com avaliações dos filmes.

- movies-service

    Microserviço que fornece informações completas para demais microserviço
